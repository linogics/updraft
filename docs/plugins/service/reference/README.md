# Services

- [updraft/studio@1](updraft-studio-1.md) Provided by the studio while it is open, not by the planner.
- [updraft/flight-analysis@1](updraft-flight-analysis-1.md) Provided by the studio while it is open, not by the planner.
- [updraft/plan@1](updraft-plan-1.md) Provided by the planner while it is open, not by the studio.
- [updraft/flights@1](updraft-flights-1.md) The logbook stored in this browser, provided by the app on every page.
- [updraft/prefs@1](updraft-prefs-1.md) The personal preferences of the user, kept in this browser, provided by the app on every page.
- [updraft/sync@1](updraft-sync-1.md) The sync of the logbook with a server, provided by the app on every page.
